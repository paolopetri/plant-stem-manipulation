## Decisions
- `tool_tip` orientation: x points out along the fork, z = `fr3_link8` z.
- URDF viewer runs in the browser (viser) instead of the yourdfpy/pyglet window, which only showed a white window here (Wayland + NVIDIA, old OpenGL). Dependencies are listed in the script header, so `uv run` is enough.
- Inertia stays required in the yaml. Without it, PhysX computes it from the convex approximation of the collision mesh with uniform density, which is wrong for printed parts. Reason added to the README.
- Task frame in Isaac Lab = end-effector body + `tool_tip_offset(ee)`. No fake mass on `tool_tip` to make it a body.
- End-effector layout: one folder per end-effector in `end_effectors/<ee>/`, name = folder name = link name. `--ee` is required (no default), `tool_tip` is required and always named `tool_tip` so tasks work for any end-effector.
- Notes: one dated log file per work day in `docs/notes/`, open items only in `docs/TODO.md`.
- Stem model v1: Isaac Lab's native Newton cable, until the meeting with the deformables expert. Whole scene on Newton.
- Repo = Isaac Lab external-project package (tasks via `isaaclab.tasks` entry point, `uv run isaaclab train --task …`). Asset data stays in `assets/`, cfgs in `src/stem_manip/assets/`.
- Skeleton files hold only spec docstrings + pointer to the TODO milestone; open items stay in `docs/TODO.md` only.
- No AI attribution in commits/PRs (CLAUDE.md + user settings).
- Curvature must use only the bending part of the relative segment rotation (swing-twist split); the total rotation angle mixes in twist.
- Stage 1 enforces the bending limit; twist rate and axial strain are computed and logged, limits added once realistic thresholds are known.
